# Sumdoku v1.0.48

- 선택창을 태블릿을 포함한 모든 화면에서 하단 가운데 바텀시트로 표시합니다.
- 배틀 대화창의 이모지·빠른 문구가 줄바꿈되어 스크롤이 생기지 않습니다.
- 이모지 전송 시 튀어 오르는 애니메이션, 버튼에서 날아오르는 이모지, 진동 피드백을 추가했습니다. 같은 이모지를 연타하면 하나의 말풍선에 ×N 콤보가 쌓이고 점점 커집니다(전송 간격 180ms).
- 화면 전환, 모달, 홈 메뉴, 설정 패널, 하단 탭, 버튼 누름에 애니메이션을 추가했습니다. 기기의 '동작 줄이기' 설정을 따릅니다.

검증: chat-motion(신규), daily-choice, settings/difficulty-language-layout, i18n-coverage, features, experience, polish, hub 통과.
