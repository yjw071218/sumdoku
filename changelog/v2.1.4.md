### 🎲 경쟁전 모드 추첨 룰렛 애니메이션 및 매칭 완료창 멈춤 수정 (`v2.1.4`)
- **경쟁전 랜덤 모드 추첨 룰렛 애니메이션 수정**:
  - 매칭 성사 화면(`#om-match-fx`)이 활성화(`.on`)되기 전에 `spinRoulette`가 먼저 호출되어 첫 틱에서 조기 종료되던 문제를 수정했습니다. 이제 4가지 배틀 모드 카드와 상단 슬롯이 매끄럽게 회전하다가 추첨된 모드로 골드 잠금(`✨ 배틀 모드 확정!`) 연출과 함께 확정됩니다.
- **백그라운드 맵 생성 시 프레임 양보(Yield) 적용**:
  - 퍼즐 생성 루프(`generateAsync`)가 12ms마다 메인 스레드를 양보하도록 개선하여, 고난도(전문가·루나틱) 맵 생성 중에도 모드 추첨 룰렛과 `5, 4, 3, 2, 1` 카운트다운이 끊김 없이 재생됩니다.
- **5초 카운트다운 종료 후 매칭 완료창에서 멈추던 현상 해결**:
  - 5초 카운트다운 대기 중 내장 루프백 서버(`BattleServer`)의 게스트 비활동 타임아웃(3.5초) 또는 이전 경기 초기화 시 전송되던 `/api/leave`로 인해 `/api/start`가 `409 not_ready`를 반환하던 문제를 수정하여, 카운트다운 종료 즉시 본 게임으로 진입합니다.

### 🎲 Fixed Competitive Mode Roulette Animation & Match-Found Screen Freeze (`v2.1.4`)
- **Fixed Random Mode Roulette Spin Animation**:
  - Resolved an issue where `spinRoulette` exited on the first tick before `#om-match-fx` received the `.on` class. All 4 battle modes now spin smoothly and lock onto the chosen mode with golden highlight effects.
- **Smooth 60fps Frame Yielding During Background Puzzle Generation**:
  - `generateAsync` now yields the main thread every 12ms so the roulette spin and `5..1` countdown never stutter.
- **Fixed Post-Countdown Game Start Freeze**:
  - Prevented the 3.5s guest inactivity timeout and stale `/api/leave` cleanup requests from causing `409 not_ready` on `/api/start` after the 5-second countdown.
