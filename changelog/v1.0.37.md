# Sumdoku v1.0.37 · 설정 제목 정리, 업적을 어워드로 통합

- **태블릿 설정 제목:** 오른쪽 제목이 항상 '설정'으로 나와 '설정'이 두 번 보이던 문제를 고쳤습니다. 왼쪽은 '설정', 오른쪽은 선택한 항목 이름(통계, 어워드, 게임 설정 등)입니다.
- **모바일 설정 상세 제목:** 항목을 눌러 들어가면 위쪽 제목이 그 항목 이름으로 바뀝니다. 뒤로 가면 다시 '설정'입니다.
- **업적 → 어워드 통합:** 통계 화면의 업적 목록을 없애고 어워드 하나로 합쳤습니다(총 18개).
  - 기존 어워드 중 '연역 추론의 달인(5회 완성)', '전문가 정복자', '연승 가도(3연승)', '마스터 마인드(5연승)'를 그대로 옮겼고, 전적을 보고 이미 달성한 것은 바로 인정합니다.
  - '첫 승리의 기쁨'은 '첫 완성'과 같은 항목이라 합쳤습니다.
  - 아무 퍼즐이나 이기면 달성되던 '스피드 러너'는 시간 조건이 실제로 있는 '번개손(초급 5분)', '쾌속 추론(중급 10분)'으로 대신합니다.
