# Sumdoku v2.1.3 릴리스 노트

## 주요 변경 사항

### 1. 경기 종료 후 자동 재매칭 및 매칭 완료창 멈춤 현상 수정
- 배틀 경기가 시작될 때 온라인 매칭 상태를 `'playing'`, 경기 종료 시 `'postgame'`으로 전환하도록 수정했습니다(기존에는 `'matched'` 상태가 유지되어 경기 종료 직후 1초 상태 갱신 타이머가 매칭 완료창을 다시 띄우고 멈추는 문제가 있었습니다).
- 온라인 배틀 세션에서는 구형 Wi-Fi 재도전 폴링(`rematchCheckTimer`)이 동작하지 않도록 분리해, 아무 버튼을 누르지 않았는데도 동일 상대와 매칭 완료창이 다시 뜨는 현상을 해결했습니다.

### 2. 매칭 완료창 5, 4, 3, 2, 1 카운트다운 및 백그라운드 맵 생성 동기화
- 매칭 성공 화면(`#om-match-fx`)에서 너무 빠르게 넘어가던 문제를 개선하여, 게임 시작까지 **`5, 4, 3, 2, 1` 카운트다운**을 표시합니다.
- 매칭 완료 즉시 백그라운드에서 배틀 퍼즐 생성이 시작되며, 5초 카운트다운과 퍼즐 생성이 모두 완료되는 시점에 맞춰 두 기기가 동시에 본 게임으로 진입합니다.

### 3. 배틀 매칭 완료창 하단 소형 미니보드(9×9) 맵 생성 연출
- 배틀 모드에서는 전체 화면을 덮는 기존 퍼즐 생성 모달(`#generating-overlay`)을 띄우지 않고, **매칭 완료창 하단에 9×9 소형 미니보드(`#om-fx-miniboard`)만 표시**합니다.
- 실시간으로 케이지가 분할되고 암호 글리프가 채워지는 과정이 방장과 참가자 모두의 매칭 완료창 하단 미니보드에 동기화되어 표시됩니다.

### 4. 매칭 탐색 중 전용 전체화면 UI (`#om-search-fx`)
- 상대를 탐색하는 동안 로비 내부의 작은 상태창 대신 **화면 전체에 크게 뜨는 전용 매칭 탐색 UI(`#om-search-fx`)**가 표시됩니다.
- 대형 레이더 스캐너 애니메이션, 경쟁전/일반전 및 매칭 구역 배지, 모드·난이도 칩, 실시간 경과 타이머, 내 프로필 카드, 매칭 취소 버튼을 제공합니다.

### 5. 경쟁전 화면 캡처 차단 및 앱 이탈 시 화면 가림 보호
- 경쟁전 배틀 진행 중 Android `FLAG_SECURE`를 활성화하여 **화면 캡처(스크린샷), 화면 녹화, 최근 앱 미리보기를 차단**합니다.
- 경쟁전 도중 홈 화면으로 나가거나 앱 전환/멀티윈도우 등으로 앱 포커스를 잃으면(`onPause`, `onWindowFocusChanged`, `visibilitychange`, `blur`), 즉시 전체 화면 보안 베일(`#integrity-veil`)이 작동해 보드와 HUD가 보이지 않도록 가립니다.
