# Sumdoku v1.0.40 · 학교·회사 Wi-Fi에서 4자리 코드 접속

학교 Wi-Fi처럼 큰 내부망은 같은 Wi-Fi라도 기기마다 IP 앞자리가 다를 수 있습니다(예: 10.20.5.x와 10.20.9.x). v1.0.35~1.0.39는 참가자 IP의 앞 세 자리가 같은 주소 254개만 확인해서 이런 망에서는 방을 찾지 못했습니다.

- **브로드캐스트로 먼저 찾기:** 참가자가 망 전체에 "이 코드 방 있나요?"를 묻고, 방장 기기가 답합니다. IP 앞자리가 달라도 같은 Wi-Fi 구간이면 바로 찾습니다.
- **실제 서브넷 확인:** 답이 없으면 휴대폰이 알려 주는 실제 망 크기를 보고 앱 안에서 최대 4,096개 주소를 병렬로 확인합니다(이전 254개).
- **Wi-Fi 주소 우선:** 내 IP를 고를 때 모바일 데이터 주소가 아닌 Wi-Fi 주소를 우선합니다.
- **못 찾을 때 안내:** 방장 화면에 표시된 IP 주소를 그대로 입력해 접속하도록 안내합니다. 학교·회사 Wi-Fi가 기기 간 통신을 막는 경우(클라이언트 격리)에는 IP로도 연결되지 않으므로, 한 사람의 휴대폰 핫스팟에 함께 연결하도록 안내합니다.
- **방장과 참가자 모두 v1.0.40**이어야 브로드캐스트 찾기가 동작합니다.

## 검증
- 새 테스트 `tests/RoomDiscoverySmoke.java`: 실제 소켓으로 브로드캐스트 찾기, `/api/hello` 확인, 없는 코드, /24·/20·/16 확인 범위 계산
- `room-code.cjs`에 IP 앞자리가 다른 방장 접속, 못 찾을 때 IP·핫스팟 안내 검사 추가
- 서버 스모크·실제 서버 2인 네트워크 테스트와 기존 테스트 통과, APK 서명 이전과 동일
- 실제 학교 Wi-Fi에서는 확인하지 못했습니다.
