# Sumdoku v1.0.46

- 언어, 목숨 소진 동작, 힌트 소진 동작, 메모 크기 및 동적으로 추가되는 선택 메뉴를 앱 테마 선택창으로 표시합니다. 현재 선택 표시, 키보드 이동, Escape 취소, 초점 복귀를 지원합니다.
- 기존 번역 키 외의 정적·동적 문구와 접근성 속성을 보완했습니다. 번역 시 메뉴 아이콘을 제거하던 문제를 수정했습니다. 추가 번역은 앱에 포함되며 실행 중 번역 서버에 접속하지 않습니다. 추가 사전은 기계 번역을 포함하므로 문구 품질 검수가 필요합니다.
- 오늘의 퍼즐 진행 상황을 일반 게임과 분리해 저장합니다. 입력, 후보 메모, 자유 메모, 실행 취소 이력, 점수, 시간, 실수 및 힌트 상태를 복원합니다. 당일 재진입과 앱 재실행 시 맵을 다시 생성하지 않습니다.
- 기기 현지 시간의 자정에 일일 진행 저장을 초기화하고, 다음 날 첫 실행 시 새 퍼즐을 생성합니다. 완료 기록과 일반 게임 저장은 별도로 유지합니다.

검증: daily-choice, i18n-coverage, i18n-check, hub, features, experience, polish 테스트 통과. 7개 외국어의 전체 DOM 번역 검사에서 검사 대상 한국어 잔여 0건. 자정 시계 시뮬레이션, 앱 재실행 복원 및 중복 시작 방지 검증 통과.
