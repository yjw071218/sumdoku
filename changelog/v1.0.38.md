# Sumdoku v1.0.38 · 자동 메모 끄기, 힌트 문장, 숫자 겹침 수정

- **자동 메모 켜기/끄기:** 자동 메모를 한 번 더 누르면(키보드 A도 동일) 꺼지고, 켜기 전에 직접 적어 둔 메모로 되돌아갑니다. 켜져 있는 동안 버튼이 강조됩니다. 끄기도 실행 취소할 수 있습니다.
- **힌트 문장:** 45의 법칙 힌트에서 `4행 9열 = 6 = 6`처럼 같은 식이 반복되던 문장을 `따라서 4행 9열 = 51 − 45 = 6`으로 고쳤습니다. 케이지가 하나뿐일 때 `16 = 16`처럼 나오던 경우와 `6은(는)` 조사도 고쳤습니다.
- **합계 숫자와 입력 숫자 겹침:** 합계가 있는 칸의 입력 숫자를 오른쪽 아래로 살짝 옮기고 약간 줄였습니다. 작은 휴대폰·배틀 화면은 더 비켜 두고, 한 칸 케이지 배지도 작게 했습니다. 배틀 합계 숫자는 일반 모드와 같은 크기를 유지합니다.

## 검증
- 새 테스트: `cell-overlap.cjs`(360px 이상 6개 화면 × 일반/배틀에서 겹침 없음), `auto-notes-toggle.cjs`(버튼·키보드로 켜고 끄기, 직접 적은 메모 복원)
- `human-hint.cjs`에 `= 6 = 6` 같은 반복 식 검사 추가
- 기존 테스트 전체 통과, APK 서명 이전과 동일
- 320px 화면(배틀 칸 약 19px)은 1~2px 정도 닿을 수 있어 검사에서 제외했습니다.
