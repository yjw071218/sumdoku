### 🎖️ 화려해진 닉네임 플레이트 · 보상 단일 장착 · 시작 버튼 하단 고정 (`v2.1.7`)
- **티어 보상 단일 장착**: 여러 보상이 동시에 켜져 테두리·배너가 겹치던 문제를 고쳤습니다. 이제 하나만 장착되며, 새로 해금한 보상은 자동 장착됩니다.
- **닉네임 플레이트 개편**: 티어가 오를수록 모양이 화려해집니다(골드 ✦ 각인 · 플래티넘 ❖ 각진 배지 · 다이아 ◆ 이중 테두리 · 마스터 ✧ 숨쉬는 오라 · 그랜드마스터 👑 불꽃).
- **플레이트 애니메이션 끊김 수정**: 그라데이션을 처음과 끝이 같은 색으로 바꾸고 한 주기씩 이어지게 해 반복할 때 튀지 않습니다.
- **시작 버튼 하단 고정**: 싱글(게임 시작)·배틀(배틀 시작/방 접속)·온라인 매칭 시작 버튼이 스크롤과 상관없이 항상 아래에 보입니다.
- **선택 칸 선 수정**: 3×3 경계 칸을 선택할 때 좌우·아래에 선이 하나 더 생기던 문제를 고쳤습니다.
- **보드 테두리 잘림 수정**: 티어 보상 테두리가 화면 좌우에서 잘리지 않도록 보드에 여백을 두었습니다.

### 🎖️ Fancier nameplates · Single equipped reward · Sticky start buttons (`v2.1.7`)
- **One tier reward at a time**: fixed overlapping frames/banners when several rewards were enabled. Newly unlocked rewards are equipped automatically.
- **Nameplate revamp**: shapes get fancier with each tier (Gold ✦, Platinum ❖, Diamond ◆ double frame, Master ✧ breathing aura, Grandmaster 👑 flames).
- **Seamless nameplate animation**: gradients now loop without a visible jump.
- **Sticky start buttons**: single-player, battle and online matchmaking start buttons stay visible at the bottom.
- **Selected cell outline fix**: no more extra lines on cells along 3×3 box borders.
- **Board frame no longer clipped**: tier reward frames are fully visible at the screen edges.
