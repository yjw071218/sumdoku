# Sumdoku v1.0.42 · Wi-Fi 방 탐색 속도 대폭 개선 (NIO 논블로킹 & 병렬 탐색)

4자리 코드로 방을 찾을 때 소요되던 지연 시간을 획기적으로 단축하여 즉각적으로 방에 접속할 수 있도록 개선했습니다.

- **브로드캐스트 & 서브넷 스캔 병렬 동시 실행:** 이전에는 UDP 브로드캐스트가 실패할 때까지 최대 2.4초간 대기한 뒤에야 TCP 스캔이 시작되었으나, 이제 두 방식이 동시에 시작되어 학교망 등 브로드캐스트가 차단된 환경에서도 대기 시간 없이 즉시 스캔이 진행됩니다.
- **Java NIO 논블로킹 초고속 스캐너 도입:** 무거운 스레드 풀(192개 스레드) 대신 Java NIO `SocketChannel`과 `Selector`를 도입하여 단 1개의 I/O 스레드로 최대 384개 주소를 동시 연결합니다. 4,096개 주소 전체 스캔 시간이 기존 12.5초에서 2.2초로 5배 이상 단축되었으며, 가까운 주소는 수십~수백 ms 이내에 발견됩니다.
- **최근 접속 IP(Last Host) 우선 검증:** 재대결이나 직전에 함께 플레이했던 친구의 IP가 저장되어 있는 경우, 전체 스캔 전 해당 IP를 1순위로 즉시 검증하여 10ms 이내 초고속으로 방에 입장합니다.
- **연결 타임아웃 최적화:** 로컬 Wi-Fi 환경에 맞게 소켓 연결 타임아웃을 180ms로 최적화하여 패킷 유실 대역에서도 지연 없이 다음 주소로 빠르게 전환됩니다.

## 검증
- `tests/RoomDiscoverySmoke.java`: 최근 접속 호스트 캐시 우선 확인(1ms), 브로드캐스트+NIO 병렬 스캔(57ms), 4,096개 주소 전체 스캔(2.2s) 속도 및 안정성 검증 통과
- `tests/room-code.cjs`, `BattleServerSmoke.java`, `battle-network.cjs` 등 네트워크 및 기존 11개 회귀 테스트 통과
