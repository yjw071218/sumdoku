# Sumdoku v1.0.31 · 케이지 다양성 복구, 쉬운 힌트 우선, 대기실 상태 구분

- **합계 칸이 2칸만 나오던 문제 수정:** v1.0.29에서 추가된 템플릿 생성 방식이 2칸 케이지만 이어 붙였고, 이런 퍼즐이 검증을 쉽게 통과해 대부분을 차지했습니다(2칸 비율 약 85~91%). 템플릿에 2~4칸을 섞고, 2칸 케이지가 60%를 넘는 퍼즐은 버리도록 했습니다. 현재 2칸 비율은 약 47~52%입니다.
- **쉬운 칸부터 힌트:** 기본 추론(확정 숫자 제외, 유일한 자리, 케이지 조합)으로 풀리는 칸이 있으면 그 칸을 먼저 알려 줍니다. 그런 칸이 없을 때만 쌍·교차 후보, 45의 법칙 순으로 어려운 기법을 사용합니다.
- **짧은 힌트 설명:** 이미 놓인 숫자로 지우는 단계는 한 줄로 묶었고, 핵심 단계만 짧은 문장으로 보여 줍니다.
- **대기실 상태 구분:** 미접속은 빈 원과 점선 테두리, 준비 중은 주황색 깜빡이는 점, 준비 완료는 초록색 체크로 표시합니다.

## 검증

- 새 `tests/generation-quality.cjs`: 난이도별 케이지 비율, 힌트만으로 끝까지 풀기, 오답 0개, 기본 추론 힌트 80% 이상
- 기존 추론·홈·대기실·배틀·화면 잘림(24개 조건) 검사 통과
- Android Release 빌드, 기존 APK와 서명 일치 확인
