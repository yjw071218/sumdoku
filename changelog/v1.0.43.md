# Sumdoku v1.0.43 · 참가자 맵 생성 실시간 UI 동기화 · '스도쿠' 표준 표기 통일 · 8개국어 다국어(i18n) 지원

배틀 시작 시 참가자 화면에서도 맵 생성 과정이 실시간으로 보이도록 개선하고, 표준어 표기 통일 및 글로벌 다국어 지원을 적용했습니다.

- **배틀 맵 생성 실시간 동기화 (Guest 화면 시각화):** 방장이 배틀 시작 버튼을 눌렀을 때 실행되는 4단계 연역 파이프라인(1. 정답판 ➔ 2. 케이지 ➔ ★2.5 초고속 유일해 ➔ 3. 인간 연역) 및 81칸 미니 보드 추론 과정이 참가자(Guest) 화면에도 실시간으로 전송되어 동일한 생성 오버레이로 시각화됩니다.
- **맵 생성 진행 동기화 API 탑재:** 백엔드에 `/api/generating` 엔드포인트 및 `/api/room` 생성 상태 동기화 필드를 추가하여 120ms 스로틀링 기반의 초경량 실시간 진행률 전송을 구현했습니다.
- **표준어 '스도쿠' 표기 전면 치환:** 프로젝트 전반(코드, UI 텍스트, 설명서 등)에 혼재되어 있던 '수도쿠' 표기를 표준 국어 표기법인 '스도쿠'로 100% 전면 치환 완료했습니다.
- **8개국어 글로벌 다국어(i18n) 시스템 구축:** 한국어(ko), English(en), 日本語(ja), 简体中文(zh), 繁體中文(zh-TW), Español(es), Français(fr), Deutsch(de) 총 8개 언어를 지원합니다. 설정 화면 및 인게임 설정 모달에서 언제든지 즉시 언어를 변경할 수 있습니다.
