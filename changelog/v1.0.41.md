# Sumdoku v1.0.41 · 분할된 학교·기관 Wi-Fi 탐색 강화 및 단축 IP 입력

학교 Wi-Fi처럼 서브넷이 여러 구역(예: 172.16.18.x 와 172.16.20.x)으로 분할되어 방송(브로드캐스트)이 경계를 넘지 못하는 환경에서도 상호 라우팅이 열려 있으면 4자리 코드로 방을 찾을 수 있도록 탐색 범위를 개선했습니다.

- **사설망 블록 중심 4,096개 주소 탐색:** 휴대폰이 보고한 단일 서브넷 크기와 무관하게 사설망 블록(10/8, 172.16/12, 192.168/16) 범위 내에서 내 IP를 중심으로 4,096개 주소(20.x 기준 12.x~28.x)를 확인합니다.
- **가까운 주소 우선 탐색:** 내 IP와 가까운 주소(동일 구역 → 인접 구역 순)부터 병렬 탐색하여 대규모 망에서도 탐색 지연을 최소화합니다.
- **끝 두 자리 단축 IP 입력:** 자동 탐색이 막힌 경우 방장의 전체 IP를 입력하지 않고 끝 두 자리(예: `18.247`)만 입력하면 내 Wi-Fi IP의 앞 두 자리를 자동으로 결합하여 바로 접속할 수 있습니다.
- **실패 시 진단 정보 표시:** 방 탐색 실패 시 내 Wi-Fi IP와 탐색한 주변 주소 개수를 안내 메시지에 함께 표시하여 연결 문제를 명확히 파악할 수 있습니다.

## 검증
- `tests/RoomDiscoverySmoke.java`: 실제 학교망 IP 사례(휴대폰 172.16.20.107, 탭 172.16.18.247)의 탐색 범위 포함 여부 검증 및 가정용 192.168 대역 경계 보존 확인
- `tests/room-code.cjs`: 끝 두 자리 단축 IP 입력(`7.20` → `192.168.7.20:8888`) 자동 결합 및 정상 접속 검증
- 기존 11개 회귀 테스트 통과 (연역, 배틀 레이아웃, 셀 일관성, 토스트, 클리핑 등)
