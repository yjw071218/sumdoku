# Sumdoku v1.0.45 · '나' 탭 클릭 시 메인 '설정' 화면 진입 개선

하단 내비게이션 바의 '나' 탭을 탭했을 때 특정 세부 패널('게임 설정')로 바로 들어가지 않고, 전체 메인 '설정' 목록 화면이 나타나도록 개선했습니다.

- **'나' 탭 진입 시 '설정' 메인 목록 노출:** 모바일 환경에서 '나' 탭 클릭 시 곧바로 '게임 설정' 상세 화면으로 진입하던 문제를 해결하여, 상단 타이틀 "설정"과 함께 설정 메뉴 전체(어워드, 통계, 최근 리플레이, 게임 설정, 플레이 방법 등)를 한눈에 볼 수 있는 메인 목록 화면으로 진입하도록 수정했습니다.
- **모바일/태블릿 헤더 타이틀 다국어 동기화:** 언어 변경 시 모바일 설정 목록 화면의 상단 타이틀도 각 언어별 설정 명칭(Settings, 設定, Ajustes, Paramètres, Einstellungen 등)으로 정확하게 동기화되도록 다국어 키(`hub_main_title`)를 8개 언어에 연동했습니다.

## 검증
- `tests/hub.cjs`: 모바일 및 태블릿 화면 크기별 허브 마스터-디테일 및 타이틀 동기화 회귀 검증 통과
- `tests/i18n-check.cjs`: 다국어 동적 언어 전환 및 실시간 DOM 텍스트 갱신 검증 통과
- `tests/features.cjs`: 기능 회귀 검증 통과
- Release APK (`Sumdoku-v1.0.45.apk`) 빌드 성공
