### ✋ 방 번호 배틀: 준비(레디)
- 방에서는 참가자가 **준비 완료**를 눌러야 방장이 게임을 시작할 수 있습니다. 방장이 설정을 바꾸거나 재대결하면 준비가 다시 해제됩니다.
- 랜덤 매칭은 지금처럼 매칭되면 바로 시작합니다.

<!-- lang:en -->
### ✋ Room battles: Ready check
- In a room, the host can start only after the guest taps **Ready**. Changing settings or a rematch resets Ready.
- Random matches still start right away.

<!-- lang:ja -->
### ✋ ルーム対戦：準備完了
- ルームでは参加者が**準備完了**を押すまでホストは開始できません。設定変更や再戦で準備は解除されます。
- ランダムマッチは従来どおりすぐに始まります。

<!-- lang:zh -->
### ✋ 房间对战：准备
- 在房间中，参加者点击**准备**后房主才能开始。房主更改设置或重赛时会取消准备。
- 随机匹配仍会立即开始。

<!-- lang:zh-TW -->
### ✋ 房間對戰：準備
- 在房間中，參加者點選**準備**後房主才能開始。房主變更設定或重賽時會取消準備。
- 隨機配對仍會立即開始。

<!-- lang:es -->
### ✋ Salas: Listo
- En una sala, el anfitrión solo puede empezar cuando el invitado pulsa **Listo**. Cambiar ajustes o la revancha lo reinicia.
- Las partidas aleatorias siguen empezando al instante.

<!-- lang:fr -->
### ✋ Salles : Prêt
- Dans une salle, l’hôte ne peut lancer qu’après que l’invité a appuyé sur **Prêt**. Modifier les réglages ou une revanche le réinitialise.
- Les matchs aléatoires démarrent toujours immédiatement.

<!-- lang:de -->
### ✋ Räume: Bereit
- Im Raum kann der Host erst starten, wenn der Gast **Bereit** tippt. Einstellungsänderungen oder eine Revanche setzen das zurück.
- Zufallsmatches starten weiterhin sofort.
