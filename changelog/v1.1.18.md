# Sumdoku v1.1.18

### 판 위에서 따라가는 힌트
- 힌트 단계마다 관련 영역, 근거 칸, 후보 소거, 확정 숫자와 화살표를 보드에 표시합니다.
- 이전·다음 버튼과 설명 목록으로 단계를 이동하고, 요약된 근거는 ‘자세히’로 펼쳐 볼 수 있습니다.
- 필요한 메모는 기존 메모 강조 또는 굵은 후보 숫자로 표시하며, 사용자의 메모를 자동 변경하지 않습니다.
- 잘못 입력한 숫자 바로잡기와 추가 힌트 탐색 경로를 도입했습니다. 짧은 추론을 찾지 못하면 후보 및 정답 안내를 제공합니다.
- 영역 합산은 선택 칸과 합산 목록을 비운 상태에서 시작합니다.

### 리플레이와 이어하기
- 모바일 리플레이 설명이 아이콘 때문에 쪼개지거나 수순 변경 시 화면 높이가 흔들리는 문제를 수정했습니다.
- 오답 수의 ‘원인 보기’에서 숫자 중복, 케이지 합 조건, 후보와 풀이를 확인할 수 있습니다.
- 종료된 배틀과 목숨이 소진된 일반 게임이 이어하기에 남는 문제를 수정했습니다. 목숨 소진 후 계속 진행하는 규칙은 유지합니다.

### 입력과 번역
- 같은 칸을 빠르게 다시 누를 때 정의되지 않은 함수 호출로 칸 선택이 중단되던 문제를 수정했습니다.
- 힌트·메모·상세 설명·리플레이의 동적 문장과 안내를 영어, 일본어, 중국어 간체·번체, 스페인어, 프랑스어, 독일어로 보완했습니다.
- battle-session 테스트가 케이지 합 라벨을 입력 숫자로 오인하던 검사를 수정했습니다.

### 검증 범위
- battle-session, touch-tap, i18n-coverage, hint-i18n, replay-continue 통과.
- 모바일 에뮬레이션 2개 화면에서 탭 96건 성공·중복 0건, 빠른 연속 클릭 및 스크롤 구분 확인.
- 7개 언어 기본 화면의 한국어 잔존 0건, 동적 문장·버튼 번역 147건 확인.
- 실제 Android 기기에서의 터치 및 Google Play 결제·광고·클라우드 연동 검증은 이번 릴리스에서 수행하지 않았습니다.
- GitHub APK는 이 릴리스에서 배포하며, Google Play AAB 빌드와 Play Console 게시 여부는 별도로 구분합니다.
- assembleGithubRelease 및 bundlePlayRelease: BUILD SUCCESSFUL, 종료 코드 0. APK 서명은 v1.1.17과 동일하며 AAB는 jarsigner 검증을 통과했습니다.
- Play 빌드의 AdMob SDK Kotlin 메타데이터 2.3/2.1 호환 메시지는 남아 있습니다. AAB 서명 검사에는 자체 서명 인증서·타임스탬프 및 JarInputStream 읽기 관련 경고가 있으며, Play Console 수락 여부는 아직 확인하지 않았습니다.
