# Sumdoku v1.0.35 · 사람이 따라 할 수 있는 힌트 + 4자리 방 코드

## 힌트
- **사람이 실제로 할 수 있는 추론만 힌트로 줍니다.** 현재 판에서 아래 기법으로 바로 확정되는 칸만 고르고, 그 칸에 필요한 이유만 설명합니다.
  - 기본 추론: 케이지 마지막 칸, 남은 숫자 하나, 숨은 싱글(행·열·박스)
  - 케이지 조합: 합 조합과 주변 숫자로 후보가 하나 남는 경우
  - 45의 법칙: 한 행·열·박스에서 케이지 밖으로 남는 빈칸이 하나인 경우
  - 쌍·교차 후보: 네이키드 페어, 박스-줄 교차, 케이지 숫자 갇힘, 45의 법칙 두세 칸 합 (앞 단계 최대 4개)
- **설명이 제대로 된 추론 순서로 나옵니다.** 같은 문장이 반복되던 문제를 고쳤고, 4단계 소거가 앞 소거에 기대면 그 단계도 순서대로 보여 줍니다. 설명은 최대 8줄입니다.
- 위 기법으로 확정할 칸이 없으면 힌트를 주지 않고 차감하지도 않습니다. 고급·전문가 퍼즐의 초반에는 이런 경우가 생길 수 있습니다.

## 안내 메시지
- '케이지 완성 보너스' 같은 안내 메시지를 화면 위쪽에 표시합니다. 더 이상 숫자 키패드나 보드를 가리지 않습니다.

## 배틀 방 코드
- **방 코드가 4자리 숫자**로 바뀌었습니다. 방마다 무작위로 정해지므로 같은 Wi-Fi에서 여러 명이 동시에 방을 열어도 코드로 구분됩니다.
- 참가자는 같은 Wi-Fi(같은 /24 대역)에서 코드가 맞는 방을 자동으로 찾아 접속합니다. 찾는 데 최대 몇 초가 걸릴 수 있습니다.
- 코드가 틀리면 접속되지 않고, 이미 다른 사람이 들어간 방에는 참가할 수 없습니다.
- 방을 못 찾으면 이전처럼 IP 주소로도 접속할 수 있습니다.
- **방장과 참가자 모두 v1.0.35**여야 합니다.

## 검증
- 새 테스트: `human-hint.cjs`(힌트 정답 일치·중복 문장 없음·설명 길이), `room-code.cjs`(같은 Wi-Fi 방 2개 구분·없는 코드·정원 초과), `toast.cjs`(8개 화면에서 안내 메시지가 보드·키패드·툴바와 겹치지 않음)
- 서버 스모크 테스트에 방 코드·정원 검사 추가, 실제 서버 2인 네트워크 테스트 통과
- 기존 브라우저 테스트 전체 통과
- APK 서명이 이전 버전과 동일
