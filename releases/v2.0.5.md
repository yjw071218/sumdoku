### ⚔️ 방 화면 개편 · 재도전 수락 · 상태바 개선
- **재도전 수락/거절**: 한 명이 재도전을 신청하면 상대가 수락해야 시작됩니다. 거절하면 "상대가 재도전을 거절했습니다"라고 표시됩니다.
- **새 방 화면**: 방 만들기를 누르면 전용 화면이 열리고, 방 안에서 배틀 모드·난이도·목숨·힌트·자동 메모·턴 시간을 모두 바꿀 수 있습니다. 참가자에게도 실시간으로 보입니다.
- **수동 시작**: 상대가 들어와도 바로 시작하지 않고, 방장이 "게임 시작"을 눌러야 시작합니다.
- **랜덤 매칭은 자동 메모 끔**으로 바뀌었습니다.
- **배틀 모드 설명**: 선택한 모드의 규칙 설명이 표시됩니다.
- **상단 상태바**: 모바일 데이터(5G/LTE 등)와 이더넷이 표시되고, VPN 사용 중에도 실제 연결이 보입니다.
- 휴대폰에서 어색하게 줄바꿈되던 문구와 경기 화면 상단을 정리했습니다.

### ⚔️ New room screen · Rematch accept · Status bar
- **Rematch accept/decline**: A rematch starts only after your opponent accepts. If they decline, you'll see "Your opponent declined the rematch".
- **New room screen**: Creating a room opens a dedicated screen where the host sets mode, difficulty, lives, hints, auto-notes and turn time — shown live to the guest.
- **Manual start**: The game no longer starts the moment someone joins; the host taps "Start game".
- **Random match now has auto-notes off.**
- **Battle mode descriptions** are shown for the selected mode.
- **Status bar** now shows mobile data (5G/LTE…) and Ethernet, even with a VPN on.
- Cleaned up awkward line breaks on phones, including the in-game header.
