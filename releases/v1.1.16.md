# Sumdoku v1.1.16

### Google Play 배포판 분리
- Gradle 배포판을 `github`(GitHub Releases)와 `play`(Google Play)로 나눴습니다.
- **github판:** 기존과 동일합니다. 같은 서명을 유지해 기존 설치본을 그대로 업데이트할 수 있고, 광고가 없습니다.
- **play판:** 앱 안의 APK 설치·화면 파일 핫 업데이트를 끄고 `REQUEST_INSTALL_PACKAGES` 권한과 파일 제공자를 제거했습니다. 업데이트 확인 버튼을 숨기고 "업데이트는 Google Play 스토어에서" 안내를 표시합니다. 업로드 키로 서명한 AAB를 만듭니다(키가 없으면 빌드 중단).

### 광고(AdMob) · 광고 제거 구매 (play판)
- 앱 시작 시 Google UMP로 개인정보 동의를 먼저 확인하고, 광고 요청이 허용될 때만 광고 SDK를 시작합니다.
- 화면 하단(게임 화면 바깥)에 적응형 배너를 표시합니다. 광고가 로드될 때만 공간을 차지합니다.
- 게임 결과 화면(일반·배틀 종료)에서만 전면 광고를 요청하며, 결과 2회마다 1회·최소 3분 간격으로 제한합니다. 게임·배틀 진행 중에는 전면 광고가 나오지 않습니다.
- 설정에 **광고 제거**(일회성 구매, 상품 ID `remove_ads`), **구매 복원**, **개인정보 및 광고 설정**(동의가 필요한 지역만), **개인정보처리방침** 항목을 추가했습니다. 구매 즉시 배너를 제거하고 이후 광고를 요청하지 않으며, 결제 확인(acknowledge)을 자동 처리합니다. 대기 결제는 완료 후 적용됩니다.
- AdMob ID를 지정하지 않으면 Google 공식 테스트 광고 ID로 빌드됩니다.

### 일일 도전 달력
- 날짜를 누르면 원이 거의 흰색(#eff6ff)으로 칠해져, 다크 모드의 밝은 숫자와 오늘 날짜의 흰 숫자가 보이지 않던 문제를 수정했습니다. 선택한 날짜는 파란 테두리와 반투명 파란 배경으로 표시하고, 오늘 날짜는 파란 원을 유지합니다. 완료(★) 날짜는 선택 시 더 진한 초록으로 표시합니다.
- 검증: daily-calendar-contrast(라이트·다크·세피아 × 일반·완료·오늘 날짜 선택, 숫자 대비 4.4:1 이상; 수정 전 코드에서는 흰색 배경으로 실패 재현)

### 보상형 광고 · 설정 상한
- 설정 가능한 목숨은 1~3개, 기본 힌트는 0~3개입니다. 스피드 레이스·타임어택의 무한 목숨 규칙은 유지합니다.
- Play판의 비배틀 게임에서 목숨 소진 시 광고로 목숨 1개를 회복하거나 포기할 수 있습니다. 부활은 게임당 최대 2회입니다.
- 힌트 소진 시 광고로 힌트 1개를 얻습니다(게임당 최대 3회). 광고 제거 구매자는 같은 횟수 안에서 광고 없이 받습니다.
- 광고 미완료·불러오기 실패에는 보상을 지급하지 않습니다. 이어하기 시 보상 사용 횟수를 보존하고 새 게임에는 이전 광고 응답을 적용하지 않습니다.
- 검증: rewards, i18n-coverage, monetization 검사 통과. GitHub APK·Play AAB 빌드 성공. Play lint 과정에서 광고 SDK Kotlin 메타데이터 2.3 / 도구 기대 버전 2.1 호환 메시지가 출력됐습니다. 실제 광고 시청·결제와 Android 기기 검증은 미실시입니다.

### 광고 제거 등급
- 부분 제거(배너·전면) / 전체 제거(보상형 광고까지 생략) / 부분→전체 업그레이드 분리.
- 한국 출시 가격안: 3,300원 / 4,900원 / 1,900원. Play Console 가격 등록은 별도이며 앱은 스토어 조회 가격을 표시.
- 기존 remove_ads 구매자는 전체 권한 유지. 업그레이드 선행 구매 및 중복 구매 방지, 보유 내역 재조회·취소·대기 처리, 광고 로드 중 구매 시 재노출 방지.
- 보상 횟수(부활 2회·추가 힌트 3회)와 배틀 제외 유지.
- 검증: ad-tiers 브라우저 검사, ad-entitlement Java 정책 검사, monetization 및 rewards 회귀 검사. 실제 Google Play 결제·환불·광고 표시 검증은 미실시.

### 광고 제거 가격 · 출시 기념 특가 (play판)
- 부분 광고 제거(`remove_ads_basic`)·전체 광고 제거(`remove_ads`)·부분→전체 업그레이드(`remove_ads_upgrade`) 3개 상품 구성.
- 전체 광고 제거에 **출시 특가** 배지와 "출시 기념 특가 (정가 5,900원 상당)" 안내를 표시합니다. 기기 시각 기준 **2026년 12월 31일까지만** 표시되고 2027년 1월 1일부터 자동으로 사라집니다. 이미 전체 제거를 구매한 사용자에게는 표시하지 않습니다. (실제 결제 가격은 Play Console에서 별도로 변경해야 합니다.)
