# Sumdoku v1.0.32 · 힌트가 보드를 가리지 않게 + UI/UX 다듬기

- **힌트 카드 위치 변경:** 힌트가 보드 위에 떠 있지 않고 툴바·키패드 자리에 들어갑니다. 힌트가 열려 있는 동안에는 키패드를 숨기고, 닫으면 다시 나타납니다.
- **보드에 근거 표시:** 힌트 대상 칸은 파란 테두리로, 추론 근거가 된 칸은 옅은 주황색으로 표시합니다. 대상 칸은 커졌다 작아지지 않고 색만 은은하게 깜빡입니다.
- **설명을 단계 목록으로:** 번호가 매겨진 단계와 결론 한 줄로 나눠 보여 줍니다. 긴 설명은 카드 안에서만 스크롤됩니다.
- **정답 가리기:** 정답은 '보기'를 눌러야 보입니다. 스스로 풀어 볼 기회를 남깁니다.
- **낮은 화면 대응:** 가로 모드 휴대폰 등에서는 카드를 압축하고, 힌트를 열면 카드가 보이도록 자동 스크롤합니다.
- **조작감:** 버튼 누름 반응, 키보드 초점 표시, 비활성 버튼 표시, 토스트·대화상자 모양을 다듬었습니다. 동작 줄이기 설정을 따릅니다.
- Esc 또는 화면 이동 시 열린 힌트를 닫습니다.

## 검증

- 새 `tests/hint-dock.cjs`: 8개 화면 크기(320×568 ~ 1280×800, 가로 740×360 포함)에서 힌트 카드와 보드 겹침 0, 정답 채우기 버튼 접근, 적용 후 카드 닫힘
- 기존 추론·생성 품질·홈·대기실·배틀·화면 잘림 검사 통과
- Android Release 빌드, 기존 APK와 서명 일치 확인

Android 실기기 화면은 별도 확인이 필요합니다.
