# Sumdoku v1.1.8

- 새 게임의 시작 전 설정과 배틀 로비의 대전 규칙을 처음 열 때와 다시 열 때 모두 접힌 상태로 표시합니다. 설정값은 유지하며 사용자가 펼쳐 옵션을 변경하는 동안에는 접지 않습니다.
- 휴대폰의 모달 CSS가 상태바 여백을 덮어쓰던 문제를 수정했습니다. 게임 설정창의 상단을 상태바에서 띄우고 화면 높이에 맞춰 최대 높이를 제한해 둥근 모서리가 보이도록 했습니다.
- 게임 설정창을 다시 열면 스크롤을 맨 위로 되돌립니다.
- Wi-Fi에 연결되지 않은 상태에서 배틀 버튼을 누르면 Wi-Fi를 켜고 같은 네트워크에 연결하라는 안내를 표시합니다. 연결 후 다시 누르면 로비로 진입하며, 인터넷이 없는 로컬 Wi-Fi도 허용합니다.
- 무음/진동, 배터리 및 네트워크 변경 이벤트를 네이티브에서 WebView로 전달해 상태바를 바로 갱신합니다. 앱 복귀 시에도 다시 확인하며 이벤트 누락에 대비한 보조 폴링을 유지합니다.
- 충전 표시를 전원 연결 여부와 함께 판정해 완충 후 충전기를 분리해도 충전 표시가 남는 문제를 수정했습니다.
- 인터넷 연결이 없으면 연결 끊김 아이콘과 접근성 설명을 표시합니다. 로컬 Wi-Fi에 연결되어 있어도 인터넷 검증이 되지 않으면 끊김을 표시할 수 있습니다.
- Android 11 이상에서 WindowInsetsController로 상태바를 숨기고, 임시 표시 방식 대신 기본 시스템 바 동작을 사용합니다. 앱 복귀와 전원 연결/해제 시 숨김을 재적용합니다.
- 알림창의 한 번 스와이프로 완전 펼침 및 제조사 시스템 알림/충전 화면의 완전 차단은 일반 앱 권한으로 보장하지 않습니다. 실기기 스와이프 검증은 미실시입니다.

검증: settings-modal-safe-area(4개 화면 크기, 일반/턴제 8개 조합, 접힘 초기화와 스크롤 복원), settings-language-layout(32개 화면 크기/언어 조합) 통과. assembleRelease 성공.
실제 Android 기기 확인은 별도입니다.

Wi-Fi 진입 검사: battle-wifi 통과(미연결 안내, 방 준비 차단, 재연결/연결 해제, 네이티브 Wi-Fi 상태 우선, 브라우저 호환).
상태바 검사: status-bar-live, status-bar, status-bar-theme, status-bar-indicators 통과. 브라우저 검사는 네이티브 상태 변경을 모의하며 실제 Android 이벤트 전달과 시스템 UI 동작 검증을 대체하지 않습니다.
