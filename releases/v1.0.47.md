# Sumdoku v1.0.47

- 다국어 설정 설명의 줄바꿈 제한을 해제하여 입력칸과 텍스트가 겹치지 않도록 수정했습니다.
- 숫자 입력칸과 앱 전용 선택 버튼을 설명 아래에 전체 너비로 배치했습니다. 메인 설정과 인게임 설정에 공통 적용됩니다.
- 8개 언어 × 4개 화면 폭(320/390/768/1024px)의 설정 패널 및 모달 텍스트 겹침 검사 통과.

- 난이도 선택창의 모드 버튼·난이도 배지·빠른 설정이 화면 너비에 맞게 줄바꿈되도록 수정했습니다. 8개 언어, 5개 화면 크기, 기본/130% 글자 크기의 80개 조합 검사 통과.
