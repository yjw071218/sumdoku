# Sumdoku v1.0.30 · 화면 잘림 수정

- 홈의 강제 세로 중앙 정렬을 제거했습니다. 이어하기와 업데이트 알림이 함께 표시되어도 상단 로고와 메뉴가 화면 위로 사라지지 않습니다.
- 홈 콘텐츠 폭을 화면 안으로 제한하고, 확대된 설명과 업데이트 문구가 줄바꿈되도록 수정했습니다.
- 공간이 부족한 홈 화면은 세로 스크롤로 모든 메뉴에 접근할 수 있습니다. 하단 내비게이션에 가려진 버튼도 끝까지 스크롤해 누를 수 있습니다.
- 배틀에서 조작부 높이를 제한하고 숫자 버튼을 글자 크기에 맞춰 조절합니다. 추론 도우미의 긴 설명만 내부 스크롤을 사용하며 보드와 키패드는 화면 안에 유지합니다.

## 검증

- 이어하기·업데이트 알림 동시 표시 및 글꼴 130% 조건을 포함한 24개 화면 검사
- 기존 배틀 11개 화면 크기의 잘림·숫자 버튼 터치 검사
- 홈·대기실 키보드 조작, 힌트·점수·Worker 회귀 검사
- Android Debug/Release 빌드와 기존 APK 서명 일치 확인

Android 실기기 화면은 별도 확인이 필요합니다.
