# Sumdoku v1.1.21

### 루나틱 합계 비공개 보완
- 합계가 `?`인 케이지를 고르면 추론 도우미의 목표 합·남은 합에 실제 합이 보이던 문제를 고쳤습니다. 이제 `?`로만 표시됩니다.
- 영역 합산에 `?` 케이지가 섞이면 총합과 45 제약 차이를 숨깁니다.
- 자동 메모가 숨겨진 합을 이용해 후보를 줄이던 문제를 고쳤습니다. `?` 케이지는 행·열·박스 규칙만으로 후보를 채웁니다.
- 리플레이 오답 설명에서도 숨겨진 합을 언급하지 않습니다.

### `?` 표시와 루나틱 화면
- `?` 합계 라벨을 빨간 배지로 바꿔 한눈에 보이게 했습니다.
- 루나틱 게임 화면에 어두운 붉은 색감, 맥박치는 보드 테두리, 실수 시 섬광·흔들림, 마지막 목숨 압박 연출을 넣었습니다. 글자 연출은 없습니다.
- 기기의 '움직임 줄이기' 설정을 켜면 흔들림·깜박임 없이 색감만 적용됩니다.

### 힌트 화면
- 힌트의 후보 표시가 칸 왼쪽 위 합계 숫자를 가리던 문제를 고쳤습니다. 후보는 실제 메모 자리에 그려지고, 합계 숫자는 항상 위에 보입니다.
- 작은 휴대폰에서 Σ 합계 라벨이 한쪽에 몰리던 문제를 고쳤습니다. 핵심 케이지만 최대 4개 표시하고 빈 자리에 배치합니다.
- 메모 안내의 '메모 없음' 문구를 'n 메모 추가 필요'로 통일했습니다.

### 기타
