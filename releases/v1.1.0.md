# Sumdoku v1.1.0 · 턴제 대결 · 서바이벌 개편 · 앱 전체 애니메이션

- 선택창을 태블릿을 포함한 모든 화면에서 하단 가운데 바텀시트로 표시합니다.
- 배틀 대화창의 이모지·빠른 문구가 줄바꿈되어 스크롤이 생기지 않습니다.
- 이모지 전송 시 튀어 오르는 애니메이션, 버튼에서 날아오르는 이모지, 진동 피드백을 추가했습니다. 같은 이모지를 연타하면 하나의 말풍선에 ×N 콤보가 쌓이고 점점 커집니다(전송 간격 180ms).
- 화면 전환, 모달, 홈 메뉴, 설정 패널, 하단 탭, 버튼 누름에 애니메이션을 추가했습니다. 기기의 '동작 줄이기' 설정을 따릅니다.

- 방을 나갔다가 새로 만들거나 참가하면 대화 내역을 비우고, 바로 재시작(재대결)하면 대화 내역을 유지합니다.
- 방 참가하기 화면을 열 때 이전에 입력한 코드와 오류 안내를 지웁니다.
- 경기 종료 후 참가자 화면에도 종료 버튼과 재시작 버튼을 모두 표시합니다.
- 배틀 리플레이에서 상대방의 스도쿠 판을 함께 보여 줍니다. 진행 중 상대의 판 상태를 기록하고, 리플레이 단계에 맞춰 표시합니다.

- 서바이벌 개편: 난이도별 압박 타이머(초급 45초 · 중급 60초 · 고급 75초 · 전문가 90초)를 도입했습니다. 시간 안에 정답을 넣지 못하면 목숨 -1·50점 감점, 상대가 정답을 넣을 때마다 내 시간이 4초 줄어듭니다. 목숨을 모두 잃으면 소진 설정과 관계없이 탈락합니다.
- 턴제 대결 모드 추가: 한 판을 함께 채우며 번갈아 한 칸씩 둡니다. 턴 제한 시간(15/20/30/45/60초)을 방 규칙으로 정하고, 시간 초과 시 30점 감점 후 턴이 넘어갑니다. 상대 턴에도 메모는 자유롭게 할 수 있으며, 판이 완성되면 점수가 높은 쪽이 승리합니다. 힌트·실행 취소는 사용할 수 없습니다.
- 자동 메모 허용 여부를 게임 시작 전(일반 게임 시작 설정·배틀 방 규칙)에서 정할 수 있습니다.


검증: TurnModeSmoke(실제 서버), battle-modes(2인 브라우저), battle-session, chat-motion, daily-choice, i18n-coverage(7개 외국어 한국어 잔여 0), features, experience, hub, room-code 통과.
