# Sumdoku v1.0.44 · 언어 설정 UI 정렬 개선 · 앱 전면 다국어(i18n) 적용 · '나' 탭 설정 기본 진입 연동

언어 설정 타이틀 및 드롭다운 UI 레이아웃을 안정적인 한 줄 형태로 개편하고, 앱 내 모든 UI 요소에 8개국어 다국어(i18n) 매핑을 완비하였으며, 하단 '나' 탭 이동 시 게임 설정 탭이 기본으로 열리도록 개선했습니다.

- **언어 설정 UI 레이아웃 정돈:** 설정 화면의 "언어 설정" 타이틀과 설명이 좁게 꺾이던 문제를 해결하기 위해, 드롭다운 폭 최적화와 말줄임/줄바꿈 방지 스타일을 적용하여 아래쪽 "목숨 소진 시 동작" 항목과 동일한 한 줄 비율과 깔끔한 여백을 갖추도록 개선했습니다.
- **앱 전체 8개국어 다국어(i18n) 전면 대응:** 언어 변경 시 한국어로 고정되어 있던 메인 홈 메뉴, 하단 내비게이션 바, 게임 상단 헤더, 서브 상태바(난이도/영역 합산/실수/시간), 액션 툴바(실행 취소/지우기/메모/메모장/힌트), 사이드바 메뉴, 옵션 설정 항목 전체 및 드롭다운 선택지에 `data-i18n` 연결과 8개 언어(ko, en, ja, zh, zh-TW, es, fr, de) 사전을 완비했습니다.
- **'나' 탭 진입 시 '설정' 탭 기본 노출:** 하단 내비게이션 바에서 '나' 탭을 탭했을 때 기존에 항상 통계 탭이 열리던 것을 사용자의 요청에 따라 '게임 설정' 패널이 기본으로 열리도록 전환했습니다. (홈 화면의 '전적 및 통계' 버튼 클릭 시에는 기존과 동일하게 통계 패널이 열립니다.)

## 검증
- `tests/i18n-check.cjs`: 내비게이션, 설정, 서브바, 히어로 섹션을 포함한 다국어 동적 언어 전환 및 실시간 DOM 텍스트 갱신 검증 통과
- `tests/hub.cjs`: '나' 탭 설정 진입 및 모바일/태블릿 허브 타이틀 동기화 회귀 검증 통과
- `tests/features.cjs`: 자동 메모, 케이지 강조, 툴바 등 핵심 기능 동작 검증 통과
- `tests/experience.cjs`: 로비 및 연역 퍼즐 인터랙션 검증 통과
- `tests/cell-consistency.cjs`: 다양한 뷰포트에서의 보드 셀 렌더링 일관성 검증 통과
- Release APK (`Sumdoku-v1.0.44.apk`) 빌드 성공
