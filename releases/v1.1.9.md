# Sumdoku v1.1.9 — 시작 시 종료되는 문제 긴급 수정

- v1.1.8에서 Android 화면 생성 전에 WindowInsetsController를 조회하여 발생할 수 있는 NullPointerException을 수정했습니다.
- setContentView 이후에 상태바 숨김을 적용하고, 호출 경로와 관계없이 DecorView를 먼저 생성하도록 보강했습니다.
- 상태바 실시간 갱신, 설정창 여백, Wi-Fi 연결 안내 등 기존 기능은 유지합니다.

검증: native-window-startup Java 모의 검사에서 v1.1.8의 초기화 예외를 재현하고 수정본의 최초/반복 호출 및 컨트롤러 미준비 상태를 확인했습니다. assembleRelease 성공.
연결된 Android 기기가 없어 실제 기기 실행은 아직 확인하지 못했습니다.

앱이 열리지 않는 경우 이 릴리스의 APK를 직접 내려받아 기존 앱 위에 업데이트하세요. 앱 삭제나 데이터 초기화는 필요하지 않습니다.
