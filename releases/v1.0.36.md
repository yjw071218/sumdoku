# Sumdoku v1.0.36 · 태블릿·배틀 화면 다듬기

- **태블릿 영역 합산:** 영역 합산을 켜도 보드 위에 캡슐이 뜨지 않고, 결과는 오른쪽 추론 도우미에만 표시됩니다. 휴대폰처럼 추론 도우미가 없는 화면에서는 이전처럼 캡슐로 보여 줍니다.
- **배틀 보드 위치:** 태블릿 배틀에서 보드 위에 캡슐 자리로 비워 두던 40px을 없애고 아래쪽 여백을 두어, 보드가 화면 바닥에 붙지 않습니다(1400×844 기준 바닥과의 간격 10px → 32px).
- **배틀 합계 숫자:** 배틀에서만 더 작은 위치·크기(칸 모서리에 붙음)를 쓰던 설정을 없애 일반 모드와 똑같이 보입니다.
- **한 칸 케이지 강조:** 한 칸짜리 케이지는 진한 파란 실선 테두리, 옅은 파란 배경, 파란 배지의 합계 숫자로 표시합니다(다크 테마 포함).
- 게임 시작 알림에 '시작 앵커 undefined개'로 나오던 문구를 실제 한 칸 케이지 수로 고쳤습니다.

## 검증
- 새 테스트 `tests/tablet-layout.cjs`: 태블릿 3종·휴대폰 2종에서 캡슐 표시 여부, 배틀 보드 아래 여백, 일반/배틀 합계 숫자 동일, 한 칸 케이지 강조
- 기존 브라우저 테스트 전체 통과, APK 서명 이전과 동일
