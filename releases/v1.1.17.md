# Sumdoku v1.1.17

### 하단 탭 바 튀는 현상 수정
- 메인·일일 도전·설정 탭을 누를 때 하단 탭 바가 12px 아래로 내려갔다가 다시 올라오던 문제를 수정했습니다.
- 원인: 화면 전환 애니메이션(`viewIn`, `translateY(12px)`)이 화면 전체에 적용돼, 그 안에 있는 고정 하단 바까지 함께 움직였습니다.
- 수정: 전환 애니메이션을 하단 바를 제외한 화면 내용에만 적용합니다. 화면 내용이 부드럽게 올라오는 효과는 그대로 유지됩니다.
- 검증: 390×800에서 GitHub판·Play판 모두 탭 전환 중 하단 바 위치가 매 프레임 고정(740px)되는 것을 확인. clipping, monetization, hub 통과.

### 테스트 정비
- `battle` 테스트가 v1.1.0에서 추가된 게스트 재대결 버튼을 반영하지 않아 실패하던 기대값을 수정했습니다(앱 동작 변경 없음). battle 통과(11개 화면 크기, 기권 4가지 경우, 결과 재시도).
