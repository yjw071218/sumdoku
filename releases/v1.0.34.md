# Sumdoku v1.0.34 · 방 참가 즉시 퇴장 버그 수정

- **방에 참가하자마자 "방이 폭파되었습니다"가 뜨며 나가지던 문제를 고쳤습니다.**
  방장이 방을 다시 만들 때(대기실 재진입, 방 다시 만들기, 배틀 후 새 방 등) 이전 방을 닫는 요청이 비동기로 늦게 도착해 **새로 연 방을 '닫힘' 상태로 바꾸고 있었습니다.** 그래서 게스트가 참가하면 첫 확인에서 바로 쫓겨났습니다.
  Android에서는 서버를 앱이 직접 종료하므로 이 늦은 닫기 요청을 더 이상 보내지 않습니다. 게스트에게는 서버 종료가 그대로 방 종료로 전달됩니다.
- 새 방을 열 때 이전 방의 채팅 기록도 함께 비웁니다.

## 검증
- 회귀 테스트 `tests/room-recreate.cjs` 추가 (수정 전 실패 → 수정 후 통과)
- 실제 Java 서버 + 브라우저 2개 네트워크 테스트, 서버 스모크 테스트 통과
- 기존 브라우저 테스트(기능·배틀·대기실·힌트·화면 잘림 24조건 등) 통과
- APK 서명이 v1.0.33과 동일 (덮어서 설치 가능)

**방장 기기도 v1.0.34로 업데이트해야** 해결됩니다. 버그는 방장 쪽 앱에서 발생합니다.
