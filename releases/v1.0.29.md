# Sumdoku v1.0.29

## 더 읽기 쉬운 화면과 편한 조작

- 홈 화면에서 시작 버튼과 보조 메뉴의 제목·설명을 구분하고 간격을 정리했습니다.
- 밝은 테마·어두운 테마·세피아 테마에 맞춰 게임 버튼, 배틀 상태판, 대기실과 결과표를 개선했습니다.
- 방 참가 오류를 코드 입력란 아래에 표시합니다. Enter 키로 접속하고 키보드로 모드와 코드 복사를 조작할 수 있습니다.
- 대화상자를 열면 초점이 안으로 이동하고, 닫으면 원래 버튼으로 돌아갑니다.
- 배틀 보드는 화면의 남은 높이에 맞춰 조절되어 숫자 입력판까지 표시됩니다.

## 추론과 배틀 안정성

- Naked/Hidden Pairs·Triples, 교차 후보 제거와 확장 45 법칙을 연역 엔진에 통합했습니다.
- 변경된 후보와 관련된 제약만 다시 검사하고 숫자 조합을 캐싱합니다. 구조화된 케이지 생성도 유일해·81칸 연역 검증을 통과해야 채택합니다.
- 힌트가 정답판을 읽거나 남은 후보를 추측하는 경로를 제거했습니다. 찾아낸 증명 중 단계가 적은 경로를 근거와 함께 보여 줍니다.
- 기권 결과를 서버가 한 번 확정하면 늦은 진행 요청이나 상대의 기권 요청이 덮어쓰지 못합니다.
- 방 생성·참가 후 상단 전환 탭을 숨기고, 참가자 퇴장·방장 퇴장·방장 전용 재도전 흐름을 반영했습니다.

## 검증

- 고정 시드 60개 퍼즐의 정답 후보 보존 및 모든 난이도의 연역 완성 검사
- 휴대폰·태블릿 11개 화면 크기의 잘림·스크롤·숫자 버튼 터치 검사
- 실제 Java 서버와 브라우저 두 개로 방장·참가자·동시 기권 검사
- 세 가지 테마, 접속 오류, 키보드 조작, 기존 점수·힌트·Worker 회귀 검사
- Debug/Release 빌드 및 기존 v1.0.28과 동일한 APK 서명 확인

실제 Android 기기 간 Wi-Fi 검증은 별도 확인이 필요합니다.

`Sumdoku-v1.0.29.apk`를 설치하거나 앱의 업데이트 확인을 이용하세요.
