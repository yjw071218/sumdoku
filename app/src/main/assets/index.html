난이도 선택

100% 논리 추론으로 찍지 않고 해결 가능하도록 설계됩니다.

썸도쿠(Sumdoku) 규칙

1. 기본 수도쿠 제약: 모든 행, 열, 3×3 박스에 1부터 9까지의 숫자가 중복 없이 들어갑니다.

2. 케이지(점선 영역) 규칙: 각 점선 테두리로 묶인 칸들의 숫자 합은 좌측 상단에 적힌 숫자와 같아야 하며, 케이지 안에서는 같은 숫자가 중복될 수 없습니다.

3. 1칸 시작 힌트: 판이 비어있지만 1칸짜리 케이지(예: 좌상단에 7)는 그 칸의 숫자가 확정 7이므로, 여기서부터 논리적 추론을 시작할 수 있습니다!

4. 찍기 금지: 모든 문제는 오직 소거법과 연역적 추론만으로 100% 정답에 도달하도록 보장됩니다.
